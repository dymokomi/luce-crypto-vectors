# Provenance

Test data only: no implementation code from any of these projects is
included. The converters that produced the line files are part of
luce-crypto (Copyright 2026 Dy Mokomi, MIT OR Apache-2.0); results this
project computed itself (BearSSL modpow outputs, `argon2id.json`) are under
the same terms (`LICENSE-MIT`, `LICENSE-APACHE`). Each source keeps its own
license, listed below.

## NIST CAVP SHA-2 (`*.rsp`)

Unmodified NIST CAVP public byte-oriented SHA-256, SHA-384 and SHA-512
ShortMsg/LongMsg response files, downloaded September 15, 2026 UTC from
https://csrc.nist.gov/CSRC/media/Projects/Cryptographic-Algorithm-Validation-Program/documents/shs/shabytetestvectors.zip
(ZIP SHA-256 `929ef80b7b3418aca026643f6f248815913b60e01741a44bba9e118067f4c9b8`;
per-file hashes in `SHA256SUMS`). US government test data. Informal use of these
vectors is not NIST/CAVP/FIPS certification.

## Argon2id (`argon2id.json`)

Deterministic test data generated by luce-crypto's `tests/argon_oracle.py`. Its
test-only oracle is argon2-cffi 25.1.0 with argon2-cffi-bindings 25.1.0 (CFFI
2.0.0, pycparser 3.0), wrapping the independent Argon2 reference; serial and
parallel reference results must agree, and the RFC 9106 result is checked
before any fixture is written.

## Project Wycheproof (`wycheproof/`)

Converted by `tools/wycheproof.py` from Project Wycheproof
(https://github.com/C2SP/wycheproof), revision
3fa63dd0344abb611f1fb1d77e119938603ea230, retrieved 2026-10-02. Apache License
2.0 (`LICENSE-APACHE`). Every test of each listed file is kept. Source checksums:
`wycheproof/SOURCE-SHA256SUMS`.

## BearSSL (`bearssl/`)

(https://www.bearssl.org/, revision 7bea48e5e850ab4cafbe68d3765cdaba13a86d6f,
retrieved 2026-10-02). Only the known-answer data is taken; the modpow inputs
come from the same HMAC_DRBG seed BearSSL uses, with results computed by
Python. Source checksums: `bearssl/SOURCE-SHA256SUMS`.

## OpenSSL (`openssl/`)

Converted by `tools/openssl_vectors.py` from OpenSSL
`test/recipes/30-test_evp_data/*.txt` (https://github.com/openssl/openssl,
branch openssl-3.5, revision adb795d9b166b7342ad1227b6241f3d31d973438,
retrieved 2026-10-02). Apache License 2.0 (`LICENSE-APACHE`), Copyright The
OpenSSL Project Authors. Every stanza of an implemented family is kept;
`openssl/SUMMARY.txt` counts the rest. Source checksums:
`openssl/SOURCE-SHA256SUMS`.

## RFCs (`rfc/`)

Extracted by `tools/rfc_vectors.py` from RFC 8439 (Appendix A) and RFC 7748
(sections 5.2 and 6.1), retrieved 2026-10-02 from https://www.rfc-editor.org/.
IETF Trust test data, used as test data. Source checksums:
`rfc/SOURCE-SHA256SUMS`.

## NIST CAVP GCM and ECDSA (`cavp/`)

Converted by `tools/cavp_vectors.py` from NIST CAVP `gcmtestvectors.zip`
(gcmEncryptExtIV and gcmDecrypt, a subset of three cases per parameter set; the
tool can emit all 47,250) and `186-4ecdsatestvectors.zip` (SigVer.rsp),
retrieved 2026-10-02 from
https://csrc.nist.gov/Projects/Cryptographic-Algorithm-Validation-Program.
US government test data; informal use is not CAVP validation. Source
checksums: `cavp/SOURCE-SHA256SUMS`.
